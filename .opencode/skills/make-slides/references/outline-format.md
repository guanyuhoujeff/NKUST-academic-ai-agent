# outline.md 的格式

大綱是簡報的設計圖。先有大綱、使用者點頭，才開始做投影片。

```markdown
# 簡報大綱

- 聽眾：金融系大三，修過投資學，沒讀過這些論文
- 時間：10 分鐘
- 要對方記住的一句話：頂刊很少直接談選擇權定價，台灣權證研究補上了個股新聞這個角度
- 風格：（使用者選定後填上 academic / editorial / stage）

| 頁 | 版面 | 標題（一句結論） | 支持它的證據（附出處） |
|---|---|---|---|
| 1 | section | 頂刊十年只有 11 篇直接談選擇權定價 | — |
| 2 | bignumber | The Journal of Finance 2015 年以後僅 11 篇 | 總筆數 11（literature.md 查詢條件） |
| 3 | table | 被引最高的三篇都在談報酬與波動，不是定價公式 | 前三筆的年份、作者、標題、被引數（literature.md 表格） |
| 4 | assertion | 台灣權證市場提供了頂刊沒有的角度：個股新聞 | 研究期間、樣本數、新聞來源（文獻卡第 3 段） |
```

## 寫大綱的規則

1. **先定那一句話。** 整份簡報只為了讓聽眾記住一句話，每一頁都要幫到它；幫不到的頁刪掉。
2. **標題是一句結論，不是一個主題。** 聽眾只看標題也要能懂這頁在說什麼。

   | 不好（主題） | 好（結論） |
   |---|---|
   | 研究方法 | 作者用 20 天的窗口比較上市初期與到期前 |
   | 實證結果 | 同一則新聞，上市初期擴大價差、到期前縮小價差 |
   | 文獻回顧 | 頂刊十年只有 11 篇直接談選擇權定價 |

3. **證據欄只放來源檔裡有的東西**，並寫出在哪個檔、哪一段。來源沒有的，不能進大綱。
4. **頁數跟著時間走**：大約一分鐘一頁。10 分鐘就是 8–10 頁，不要硬塞。
5. **版面要有變化**：同一種版面不要連續超過 3 頁；每換一個段落放一頁 `section`。各版面的用法見 `layouts.md`。
