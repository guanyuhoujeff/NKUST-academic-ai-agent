# 做簡報

簡報好不好，九成決定在動手排版之前：要對誰講、要他記住什麼、每一頁說哪一句話。所以順序是**先設計、再製作**，而且設計是你和使用者**一起談出來的**：談主軸 → 寫大綱 → 使用者確認 → 選風格 → 才排版。

這個流程有一支「流程管家」程式幫你記住做到哪、下一步是什麼。

## 唯一要記住的規則

**每一輪對話，你的第一個動作都是執行這一行，然後照它印出來的指示做：**

```
python .opencode/skills/make-slides/scripts/slides.py next
```

（Windows 的 `python` 無效時改用 `py`。第一次執行若說找不到 `pptx`，先執行 `python -m pip install --user python-pptx`。）

它會告訴你現在在哪一關、這一關要做什麼、做完要執行哪個指令。**不要憑記憶跳到後面的步驟**——每一關都有程式把關，跳關會被擋下來。

## 流程全貌（給你和使用者看的地圖）

| 關 | 做什麼 | 過關條件 | 指令 |
|---|---|---|---|
| 1 | ★ 讀完來源檔（`literature.md`、`notes/`、`sources/`），向使用者提 2–3 個不同的主軸（講法），**停下來等他挑** | 使用者選了，或說出自己的想法 | `slides.py angle "…"` |
| 2 | 照選定的主軸寫大綱 `outline.md` | 每一頁的證據都有一句從來源**原樣抄**的引文，程式在來源檔裡找得到 | `slides.py check-outline` |
| 3 | ★ 把大綱貼給使用者，**停下來等他確認** | 使用者說可以（要改就改完重新檢查、再給他看） | `slides.py approve` |
| 4 | ★ 請使用者選風格，同時問他要不要逐頁討論，**停下來等他回覆** | 使用者選了 | `slides.py theme <代號>` |
| 5 | 照大綱寫 `deck.json`，產生簡報 | 字型、大綱、份量、語言、來源五項檢查全過 | `slides.py build` |

三個 ★ 是一定要停下來的地方：貼出內容、問完問題，那一輪就結束，等使用者回覆。

**逐頁討論（選用）**：在第 4 關，使用者**明確說**要一頁一頁討論時，才用 `slides.py theme <代號> --page-by-page`。之後每一頁都是：寫好這一頁 → 貼給使用者看 → 停下 → 他說可以就執行 `slides.py page-ok` 進下一頁。使用者沒有明說，就是預設：整份做好再給他看。中途他說「剩下的你直接做完」，執行 `slides.py pages-off`。

例外：使用者明說「全部交給你、不用問我」時，一開始就執行 `slides.py auto "他的原話"`，所有停頓點都跳過。他只是選了風格或說「整份做好再給我看」**不算**，那仍然要走完上面的每一關。

## 四條不能破的規矩

1. **內容只能來自來源檔（`literature.md`、`notes/`、`sources/`）。** 來源沒寫的案例、模型名稱、數字、結論，不可以出現在大綱或投影片裡。
2. **標題是一句結論，不是一個主題。**「研究方法」是主題；「作者用 20 天的窗口比較上市初期與到期前」是結論。
3. **要點要有具體事實。** 每條要點盡量帶一個從來源原樣抄的數字、年份、樣本數或名稱；「表現優異」「效果顯著」這種形容不算。
4. **回報時把程式印出的檢查結果原樣貼上**，不要用自己的話轉述。有任何一行沒通過，就照實說沒通過。

## 產出物

- `outline.md`：簡報的設計圖。聽眾、時間、核心訊息、風格、逐頁大綱與引文。
- `deck.json`：每一頁的實際內容。之後要改簡報，改這個檔再執行 `slides.py build`。
- `slides.pptx`：16:9，文字與表格都是 PowerPoint 原生物件，可以直接點進去改。
- `slides.pdf`：預覽用（電腦有 LibreOffice 才會產生）。

## 想多了解時再讀

- `references/outline-format.md`：大綱怎麼寫才好，附範例。
- `references/layouts.md`：六種版面各自的用途、`deck.json` 的完整寫法、圖示（icon）清單。
- `references/themes.md`：三套風格的說明。

## 失敗怎麼辦

- 任何指令印出「未通過」「還不能…」「BUILD FAILED」：照它說的修，再執行它叫你執行的指令。
- 同一關連續 3 次過不了：停下來，把程式印的訊息原樣回報給使用者。
- 引文一直對不上：回來源檔重新複製那一句，不要憑印象打字。
